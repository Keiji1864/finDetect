# ФинДетектив

Android-приложение для учёта доходов и расходов, которое предупреждает, что деньги закончатся раньше следующего поступления, пока ещё есть время что-то изменить.

## Зачем это нужно

Если доход приходит неравномерно (подработка, стипендия, фриланс), нехватку денег замечаешь уже по факту, когда занимать поздно. Предупредить может только регулярный учёт трат, но его бросают в первые 1-2 недели: усилия нужны каждый день, а результат виден раз в месяц.

ФинДетектив решает обе части проблемы: вносить траты можно за пару секунд, а игровые механики помогают не бросить привычку, пока не накопится достаточно данных для полезного прогноза.

Для кого: молодые люди 18-30 лет с небольшим и нерегулярным доходом: студенты с подработкой, начинающие специалисты, фрилансеры.

## Что умеет приложение

- Быстрый ввод расходов и доходов
- Статистика и аналитика трат по категориям
- Прогноз остатка бюджета до следующего поступления и предупреждение о риске нехватки денег
- Геймификация: ежедневные достижения и напоминания

Приложение работает независимо от банков: учитывает наличные, переводы и любые карты.

## Технологии

- Android: Kotlin, Jetpack Compose, Ktor, Room, DI Hilt
- Backend: Java, Spring Boot
- Сборка: Gradle
